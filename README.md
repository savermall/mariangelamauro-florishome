# Mariangela Mauro · FlorisHome — sito (bozza)

Sito vetrina one-page per la fioreria **Mariangela Mauro FlorisHome** (Reggio Calabria, Viale G. Amendola 29).

## Contenuto
- `index.html` — pagina unica (hero, storia, servizi, galleria, ricorrenze, contatti, mappa)
- `style.css` — stile elegante (serif Cormorant Garamond + Jost, palette avorio/verde/rosa/oro)
- `opt/` — 32 foto ottimizzate (max 1600 px, q82), scaricate dal profilo Instagram dell'attività
- `img/` — originali scaricati (non versionati)
- `meta.json` — elenco foto + caption originali

## Da confermare col cliente (segnaposto nel sito)
- telefono / WhatsApp
- email
- orari di apertura (highlight IG "ORARI")
- elenco servizi e eventuali prezzi
- testo "chi siamo" definitivo
- partita IVA / ragione sociale (per il footer)
